# wasm-plasma-rs

A real-time plasma effect rendered in the browser using Rust and WebAssembly. The shader is a port of the GLSL plasma from [4rknova.com](https://4rknova.com/blog/2016/11/01/plasma), running at 60 FPS on a 512×512 canvas. Move your mouse over the canvas to rotate and warp the plasma.

## Prerequisites

- [Rust](https://rustup.rs/) (stable toolchain)
- [wasm-pack](https://rustwasm.github.io/wasm-pack/installer/)
- A static file server (e.g. `python3`, `npx serve`, or VS Code Live Server)

Install `wasm-pack` if you don't have it:

```sh
cargo install wasm-pack
```

## Build

```sh
wasm-pack build --target web
```

This compiles the Rust crate to WebAssembly and places the output in the `pkg/` directory.

## Run

Because the page loads a `.wasm` file via ES module imports, it must be served over HTTP (not opened as a `file://` URL).

**Python (built-in):**
```sh
python3 -m http.server 8080
```

**Node / npx:**
```sh
npx serve .
```

Then open [http://localhost:8080](http://localhost:8080) (or the port shown) in your browser.

## Usage

| Action | Effect |
|---|---|
| Move mouse left/right | Rotates the plasma horizontally |
| Move mouse up/down | Rotates and changes depth of the effect |

The current FPS is displayed in the top-left corner of the canvas.

## Project structure

```
src/lib.rs        # Rust/WASM source – plasma shader & animation loop
index.html        # Entry point – loads the WASM module
pkg/              # Generated by wasm-pack (do not edit manually)
Cargo.toml        # Rust package manifest
```
